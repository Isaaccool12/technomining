Прототипы «ТехноМайнинг»

Интерфейс приложения сервисного инженера. Данные в памяти страницы, сервер не нужен.

v1 — отчёты и замеры Отчёты, замеры с допусками, сетка «цилиндр × точка», фото, PDF на бланке v2 — структура приложения 0.2 Этапы отчёта из 0.2, ТО по чек-листу, роли, аналитика v3 — полный функционал 19 этапов, документы с поиском, переработки, админка, корзина, дубли, память, аннотация фото, печать PDF Оригинал 0.2 Загружает настоящий index.html из репозитория — интерфейс один в один
Тяжёлые библиотеки (OCR, pdf-lib, шрифты) лежат внутри APK и в репозиторий не выложены.
