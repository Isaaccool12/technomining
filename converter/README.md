# Конвертер заводских инструкций → пакеты приложения

`kpdf2pack.py` превращает заводскую инструкцию Komatsu (PDF) в пакеты приложения: по ZIP на каждый агрегат.
Правила разбивки — `rules_komatsu.csv`, память переводов EN→RU — `tm_komatsu_en_ru.csv`.

## Запуск в GitHub Actions (без ПК и без лимита по времени)

1. **Положить PDF в релиз `pdf-library`** (один раз на файл). Откройте Releases → «Библиотека PDF для конвертера» → ✏️ Edit → перетащите PDF → Update release.
   Размер файла — до 2 ГБ. Имя файла пишите латиницей, по обозначению инструкции, например `SEN02158-15.pdf`: кириллицу и скобки GitHub заменяет точками.
   Вместо релиза можно дать публичную ссылку на Яндекс Диск, Google Диск или прямую ссылку на файл.
2. **Запустить:** Actions → «Конвертер PDF → пакет» → Run workflow. Заполнить поля:
   - `pdf` — имя файла в релизе или ссылка;
   - `machine` — модель, например `D275A-5`;
   - `doc` — обозначение инструкции;
   - для английской инструкции дополнительно `parallel` (русская пара) и `parallel_doc`.
3. **Забрать результат:** откройте страницу запуска → Artifacts → `<модель>_<обозначение>_pack`. В архиве ZIP-пакеты, `summary.json`, `log.txt` и, если есть, `untranslated.csv`. Архив хранится 30 дней.

Одна задача может идти до 5 часов. Английская HD785-7 обрабатывается примерно за 7 минут.

Для машинного перевода (`mt = claude`) добавьте ключ: Settings → Secrets and variables → Actions → New repository secret, имя `ANTHROPIC_API_KEY`.

## Запуск на ПК

```
pip install pymupdf pillow
python kpdf2pack.py <pdf> <папка_вывода> --machine HD785-7 --doc SRU05900-01
python kpdf2pack.py EN.pdf out --machine D275A-5 --doc SEN02158-15 --parallel RU.pdf --parallel-doc SRBM026307
```

Основная копия конвертера — эта папка репозитория. Копию в `D:\ClAUDE\ТехноМайнинг\Пакеты для приложения\Конвертер\` обновляйте отсюда.
